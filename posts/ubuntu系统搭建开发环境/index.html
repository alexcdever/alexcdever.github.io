更新于 2026-10：这是一份「新机器从上电到能开发」的顺序清单，每个工具的详细说明在我的开发环境之Linux篇里。原文里失效的几条（get.daocloud.io 一键脚本、Linuxbrew 仓库、raw.github.com 域名）已经替换。

以 Ubuntu 22.04 / 24.04 为例。

1. 换成国内镜像源

清华、阿里云、中科大等机构都提供 Ubuntu 镜像源。

  • 22.04 及更早，源列表在 /etc/apt/sources.list：

    1

    sudo sed -i 's|http://archive.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g; s|http://security.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list

  • 24.04 起改用 deb822 格式，源列表在 /etc/apt/sources.list.d/ubuntu.sources，同样的替换：

    1

    sudo sed -i 's|http://archive.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g; s|http://security.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list.d/ubuntu.sources

  • 改完更新索引：sudo apt update

2. 创建 ssh 密钥

ssh-keygen -t ed25519 然后一路回车，公钥在 ~/.ssh/id_ed25519.pub，把它贴到需要的地方即可。

3. 安装常用的工具

sudo apt install curl git vim zip autofs cifs-utils net-tools build-essential file -y

4. 更新并升级系统内的组件和工具

sudo apt update && sudo apt upgrade -y && sudo apt autoremove -y && sudo apt autoclean -y

5. oh-my-zsh 和 zsh

  1. sudo apt install zsh -y

  2. sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"（原文的 raw.github.com 已不推荐）

  3. 装插件：

    1
2

    git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting

  4. 修改 .zshrc，把 zsh-autosuggestions 和 zsh-syntax-highlighting 加到 plugins 数组里

6. docker

原文的一键脚本都不要再用了：

  • curl -sSL https://get.daocloud.io/docker | sh —— DaoCloud 的这个安装脚本服务早已停止（域名还能解析，但连不上）
  • curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun —— 一键脚本官方只推荐用于测试环境，而且 --mirror Aliyun 指向的公共加速器在 2024 年已经关停

正式一点的装法（官方 apt 仓库 + keyring），步骤见我的开发环境之Linux篇；国内拉镜像的现状那里也一并写了。

7. Homebrew（原 linuxbrew）

# 依赖
sudo apt install build-essential procps curl file git -y
# 安装（Linuxbrew 的两个仓库都已归档，安装脚本从 Homebrew 官方仓库取）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
# 加入 PATH
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.zshrc
eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"

8. sdkman

curl -s "https://get.sdkman.io" | bash，装完执行 source "$HOME/.sdkman/bin/sdkman-init.sh" 或新开一个终端。
